# Security Policy

## Supported Versions

Security fixes are provided for the latest minor release.

| Version | Supported |
| --- | --- |
| 1.2.x | Yes |
| < 1.2 | No |

## Reporting a Vulnerability

Use GitHub private vulnerability reporting for this repository. If that
channel is unavailable, contact `tulgamaidar3@gmail.com` with the subject
`[MongPass Security]`.

Include reproduction steps, affected routes, impact, and a proposed fix when
possible. Do not open a public issue or include real user data.
