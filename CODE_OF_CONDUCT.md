# Code of Conduct

## Our Standard

MongPass contributors commit to a respectful, inclusive, and harassment-free
community. Be constructive, assume good intent, respect cultural context, and
focus criticism on ideas and code.

Unacceptable behavior includes harassment, discrimination, threats, sharing
private information, and sustained disruption.

## Enforcement

Report conduct concerns privately to the project maintainers through GitHub's
private reporting channel or the security contact in `SECURITY.md`.
Maintainers may edit or remove contributions and temporarily or permanently
restrict participation when necessary.

This policy applies in repository spaces, Discussions, issue trackers, and
project events.
